ShopMate

An AI sales assistant for an online fashion store

Personal project, 2026. Python, LangGraph, Gemini, Qdrant, FastAPI.

31 of 33 answers correct on a test set I locked and ran only once.

Shoppers ask in Vietnamese about products, returns and their orders. The agent searches a store of 250 products, can only read data, stops after 8 steps, and asks the customer before it opens a support ticket. A check in code blocks any reply that quotes a wrong price.

  • Searches typed without Vietnamese accents got much better (+0.43 MRR) after I combined keyword search with vector search.
  • Median reply time is 2.6 seconds, at about US$0.9 per 1,000 conversations.
  • What didn't go well: pulling filters like colour and type out of a question scored 23/24 on my dev questions but 6/10 on the test set. My prompt fit the dev questions too closely.

SentinelAI

A system that finds traffic violations in camera video

Personal project, 2026. Python, YOLO11, OpenCV, FastAPI.

Retraining on cleanly split data halved false alarms on a camera the model had never seen.

It looks for riders without a helmet, motorbikes carrying more than two people and red-light running. Each vehicle is tracked across frames, and every alert goes to a review page where a person confirms or rejects it.

  • The original dataset had frames from the same video in both training and test, so the first score (0.81 mAP50-95) looked better than it was. Split by video, the honest score is 0.64, or 0.93 mAP50.
  • On a new camera, false alarms went from 32 to 16 per minute.
  • Not measured yet: how many real violations it catches. The test clip had none.

DevPrep

An AI mock-interview platform

Capstone, team project, FPT University, 2026. .NET 8, FastAPI, Gemini, ChromaDB.

I built the interview and grading services. Gemini grades each answer against reference answers found with RAG, on a rubric weighted 50/30/20 for knowledge, problem solving and communication. I also worked on the face and voice checks that verify the candidate before and during the interview.

The repository belongs to the team and is private. I'm happy to walk through it in an interview.

How I work

Measure first. I keep a test set that I run once, and I report a weak result instead of running it again until it looks good.

Put limits in code. An LLM can talk its way around a prompt. It can't talk its way around a step limit, read-only tools or a price check.

Make every request visible. I trace each request with the time and cost of every step, so when something breaks I know where to look.
