ShopMate — AI sales assistant for an online fashion store

Personal project, 2026
  • Python
  • LangGraph
  • Qdrant
  • Gemini
  • Guardrails
  • bge-m3
  • Saleor GraphQL
  • FastAPI
  • GitHub Actions
  • Web Components
  • An agent that answers product, return-policy and order-status questions over a Saleor store with 250 products. Read-only tools, at most 8 steps, and support tickets only after the customer confirms.
  • Hybrid search for Vietnamese typed without accents: fusing an accent-folded keyword index with bge-m3 vectors raised MRR by +0.43 (95% CI 0.27–0.58) over the baseline.
  • A guardrail in code, not in the prompt: any sentence that quotes a price must match the SKU it names, or the answer is replaced.
  • Evaluated like an experiment: 104-question golden set, dev/test split, test locked by hash and pre-registered before its single run. CI runs 1,600+ offline tests, result-integrity checks and secret scanning.
  • An embeddable chat widget, and an operator monitor that shows every request from question to reply.

SentinelAI — Traffic-violation detection from camera video

Personal project, 2026
  • Python
  • PyTorch
  • YOLO11
  • OpenCV
  • Object tracking
  • FastAPI
  • Kaggle GPU
  • Human review
  • Finds violations in fixed traffic-camera video: riders without a helmet, motorbikes carrying more than two people, and red-light running checked per lane, with the traffic-light colour read by OpenCV.
  • YOLO11 trained on Kaggle to detect helmet, no-helmet and motorcycle. Each vehicle is tracked across frames, so a violation is reported once per vehicle, not once per frame.
  • The original dataset put frames of the same video in both train and test: 75.6% of test images had a neighbouring frame in training. I re-split it by video and reported the honest numbers.
  • Tested on a camera the model never saw, with every alert checked by eye: the retrained model halved false alarms, from 32 to 16 per minute. Recall on that clip is not measured yet.
  • A FastAPI web app streams the annotated video, and a review page lets a person confirm or reject each alert. Decisions export as corrected labels for the next training round.

How I work

The habits behind the numbers above.

Measure before trusting

Golden sets, a dev/test split, confidence intervals, and a test set that is run once. A weak result is reported, not re-run.

Guard in code

Limits an LLM cannot talk its way around: step caps, read-only tools, confirmation before any action, checks on every price.

See every request

Each request is traced from intent to reply, with latency and cost per step, so failures have an address.
